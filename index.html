🛠️ AlmaDL Utilities

Strumenti per la gestione di file all'interno dei workflow dei servizi AlmaDL

Perché usare questi strumenti?

Gli script funzionano al 100% sul tuo browser
I tuoi file rimangono privati sul tuo PC
Non necessitano di installazione
Funzionano offline una volta caricati
Utilizzo libero, codice aperto
Interfaccia moderna e intuitivia
📄

AlmaDL PDF Splitter

Suddividi PDF di grandi dimensioni.

  • Seleziona la dimensione massima dei file (default 20MB)
  • Distribuzione automatica delle pagine
  • Download dei singoli file o massivo
  • Mantiene tutto il contenuto dei PDF
Apri AlmaDL PDF Splitter → 🧹

AlmaDL ZIP Cleaner

Rimuove i file e le cartelle di sistema macOS dagli archivi ZIP.

  • Rimuove le cartelle __MACOSX
  • Rimuove i file .DS_Store
  • Pulisce i file resource fork
  • Mostra lo spazio disco guadagnato
Apri AlmaDL ZIP Cleaner → 🔧

AlmaDL Filename Cleaner

Pulisce e standardizza i nomi file nelle cartelle ZIP.

  • Spazi → underscore
  • Punti → trattini (ad eccezione delle estensioni)
  • Gestisce possibili duplicati
  • Rimuove i caratteri speciali
Apri AlmaDL Filename Cleaner → 📝

AlmaDL README Generator

Genera un README file per i dataset e il software

  • Carica il file JSON con i metadati del dataset
  • Legge i file e le cartelle all'interno degli archivi ZIP
  • Integra le informazioni del JSON con documentazione aggiuntiva
  • Genera il README file in formato .docx e .txt
Apri AlmaDL README Generator → 📄

AlmaDL Cover Generator

Genera una copertina per i documenti

  • Carica il file JSON con i metadati del documento
  • Controlla e modifica le informazioni prima di generare la copertina
  • Gestisce le licenze d'uso
  • Genera il README file in formato .docx e .pdf
Apri AlmaDL README Generator →
